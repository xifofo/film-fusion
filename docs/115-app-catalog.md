# 115 授权应用目录

新版“添加 115 网盘”和“重新授权”共用应用选择器，支持名称/ID 搜索、滚动分页、按 ID 回显及手动输入。选项显示 `Client ID · 应用名称`，提交给原扫码接口的仍是字符串 `client_id`，不保存显示名称，不改变已有网盘凭据。

应用 ID 统一在“系统管理 → 数据字典 → 115 开放平台应用”（编码 `cloud.115_apps`）维护。关闭再打开应用下拉会读取最新候选。类型及项的管理规则、接口与旧 JSON 迁移见 [通用数据字典](dictionaries.md)。

初始目录位于 `app/database/catalogs/115_apps.json`，从本地 `115 app_id (1).json` 整理了 1,075 个应用，仅保留公开 ID、名称、启用状态及排序，未导入图标 URL。该目录是候选名单，不代表应用已通过实际扫码验证，也不是授权白名单。115 项值为 1–20 位数字且首位非零，长 ID 始终作为字符串处理。手动输入未收录的 ID 仍可发起授权。

新版表单读取通用候选接口 `GET /api/dictionary-options/cloud.115_apps`，只使用启用项。停用、已删除或未收录的现有 ID 由表单保留原值；类型停用或目录加载失败时显示错误，用户仍可切换手动输入。

`GET /api/auth/115/apps` 为兼容入口，与 115 授权接口复用管理员鉴权及 `cloud-storage` API Token 范围，支持 `page`、`page_size`（1–100）、`q`（最多 100 字）及重复 `ids`（最多 100 个）。响应 `data` 包含 `list`、`total`、`page`、`page_size`；`ids` 回显返回全部匹配启用项。停用类型在此旧入口返回空列表，不回退内置名单。

上线需同时更新后端和新版前端；旧版前端继续使用原手动授权接口。
