# 目录配置中的 115 网盘浏览

在「目录配置」中点击一条配置的「浏览网盘」，选择 Cookie 或 OpenAPI 后读取目录。账号沿用该目录配置关联的云存储；目录列表、面包屑和文件均来自所选访问方式，不自动切换认证方式。

## 请求与分页

- 浏览列表只读取用户选择的一页。切换目录、翻页、刷新由用户操作触发，不预取下一页，不后台扫描。
- 浏览和本功能的目录 STRM 生成共用进程级请求限制：同时最多两个 115 请求，相邻请求启动间隔至少一秒。
- 认证失败直接返回错误，不自动刷新 Token、重登 Cookie、重试或回退至另一访问方式。
- 加载账号配置、查询生成任务进度及停止任务本身不请求 115。

## 重新生成 STRM

文件可以单独生成。对目录点击生成后，后台按页遍历该目录及子目录，界面显示处理进度并提供停止按钮。目录遍历使用同一个请求限制，不改变浏览列表的手动翻页行为。

后端根据 115 返回的目录祖先 ID，匹配当前用户、同一云存储的目录配置，优先使用最近的配置。未匹配、配置冲突或无法确认目录归属时不生成。

生成沿用 `CloudDirectory` 的保存路径、目录名称、内容前缀、URI 编码、包含后缀、排除后缀及最小文件大小。保留网盘中的相对目录结构，不重新识别、移动或重命名网盘文件。

浏览响应中的选择凭证由服务器签名，生成接口不接受客户端自报文件路径。单文件生成使用刚读取的元数据，不为了生成本地 STRM 额外请求 115。已失效的选择凭证需要用户刷新列表。

## API

接口使用现有认证和 `directories` API Token 权限，`:id` 为目录配置 ID。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/directories/:id/browser` | 按 `access_method`、`cid`、`offset`、`limit` 读取一页 |
| POST | `/api/directories/:id/browser/strm` | 提交浏览结果的 `selection_token`，生成文件或启动目录生成 |
| GET | `/api/directories/:id/browser/jobs` | 找回该入口最近的任务，重新打开页面后仍可查看、停止 |
| GET | `/api/directories/:id/browser/jobs/:job_id` | 读取本地任务进度 |
| DELETE | `/api/directories/:id/browser/jobs/:job_id` | 请求停止该任务 |

目录任务由用户显式提交后才开始，服务启动不会自动恢复或发起遍历。关闭面板不会停止任务；重新进入对应目录配置可找回任务并停止。服务关闭会取消任务；服务重启后内存中的任务记录清除，已生成文件保留。

最多同时运行两个目录生成任务，同一云存储最多一个。遍历限制为 64 层、10 万目录、10 万个 STRM 文件和 24 小时，错误摘要最多保留 50 条；超过限制会明确停止并保留已有结果。普通 STRM 可以重新写入，相同内容不重复写入；受整理任务管理的文件保留原状。

## 开发验证边界

测试只使用注入的模拟 Transport、临时数据库及临时本地目录，不使用真实 115 凭据，不启动应用后台服务。SDK 协议、分页、限流、匹配、生成和取消测试不代表真实 115 账号验收。
