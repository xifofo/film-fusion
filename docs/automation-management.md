# 自动化复用与管理

自动化中心继续使用 `/api/automations` 的来源、流程和运行模型。RSS 与 115 目录流程共用以下管理功能。

## 页面入口

- **复制**：流程卡片上的复制按钮。新名称自动避重，可以统一替换重复使用的账号、目录、下载器、分类、地址及通知渠道。新流程停用，创建后进入编辑器，不复制扫描基线、历史运行或异常记录。
- **流程参数**：卡片更多菜单或 RSS 流程画布工具栏。支持文本、数字、布尔参数，并可将多个节点字段绑定到同一参数。
- **保存为模板**：卡片更多菜单。模板保存在服务器，页面“流程模板”支持搜索、使用、编辑说明、删除及 JSON 导入导出。使用模板进入换绑界面，创建独立且停用的流程。
- **版本历史**：卡片更多菜单。对比来源、参数、节点和连线，恢复旧版本时创建新版本并停用。已启动任务保留启动时的定义和参数快照。
- **分组与批量操作**：卡片复选框以及列表分组筛选。支持批量启用、停用和设置分组；分组留空表示未分组。一次批量操作在同一事务中完成。
- **异常提醒**：更多菜单“分组与异常提醒”。独立设置来源错误、连续失败阈值、节点执行时长与同类提醒间隔。

## 参数格式

定义的 `parameters` 是标量键值表，最多 100 项；名称为字母或下划线开头、最多 64 位的字母数字下划线组合，不允许原型保留名称。服务端校验参数类型并限制单项文本大小。

```json
{
  "parameters": { "library": 7, "category": "电影", "channel": "default" },
  "nodes": [{
    "id": "organize", "type": "organize_strm",
    "config": { "cloud_directory_id": 7, "category": "电影" },
    "parameter_bindings": { "cloud_directory_id": "library", "category": "category" }
  }]
}
```

`parameter_bindings` 优先覆盖对应配置字段。配置值写为 `$params.library` 时保留原生类型；文本中的 `{{params.category}}` 插入字符串。保存校验、前端模拟和执行使用相同的解析规则；数据库保留可编辑的引用。`notification.channel` 可选 `default`、`telegram`、`webhook`，指定渠道仍需在系统中启用并配置完整。

## 模板与分享

服务器模板保留配置值，适合同一实例复用。分享格式为 `film-fusion-automation-template`、版本 1，文件上限 1 MiB。导出清除已知账号和资源绑定、静态地址、常见凭据字段及参数值，保留节点结构和动态引用；接收者在创建前重新填写参数和资源绑定。自定义文本、请求体和说明可能包含用户填写的信息，导出不是任意内容的凭据识别器。

原有 RSS 流程文件格式仍可导入。该旧格式导出解析后的有效节点值，再使用原有资源清理规则；新的模板文件格式保留参数和绑定结构。

## 版本与异常行为

每次保存来源或流程，事务内记录修改前后配置，流程版本递增。已有流程在首次读取版本历史或保存时建立当前基线，无法追溯功能启用前未记录的修改。恢复请求必须携带当前 `expected_version`，过期请求拒绝覆盖。启停、分组和提醒策略属于运行管理设置，不单独产生配置版本。

健康检查随自动化服务启动，每分钟检查启用提醒的来源。连续失败包含失败及部分成功，最近成功会中断连续计数。节点超时只检查运行中的节点，等待调度、计划延迟和轮询等待不算卡住。停用来源后停止提醒；恢复正常后清除活跃异常。提醒走系统通知路由 `automation.triggered`，页面同时展示异常和通知投递失败原因。投递成功及失败尝试都会遵守冷却间隔，重启后仍保留冷却状态。默认关闭异常提醒。

## 数据与接口

启动迁移新增 `automation_settings`、`automation_templates`、`automation_revisions`、`automation_alerts`。删除自动化会清理其设置、版本和异常；已保存模板是独立副本。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET / POST | `/api/automations/templates` | 列表 / 创建模板 |
| PUT / DELETE | `/api/automations/templates/:id` | 更新 / 删除模板 |
| PUT | `/api/automations/:id/settings` | 保存分组和提醒策略 |
| POST | `/api/automations/batch` | `source_ids`、`action`（enable/disable/group）、`group_name` |
| GET | `/api/automations/:id/revisions` | 当前基线及已保存历史 |
| POST | `/api/automations/:id/restore` | `revision_id`、`expected_version` |

上述接口处于原有认证路由下。仪表盘返回 `settings` 和当前活跃 `alerts`。原有创建、来源保存、流程保存及全量更新接口支持参数化定义，全量更新接受可选 `expected_version`。

## 验证范围

服务测试覆盖参数解析、真实调度器运行快照、版本隔离和恢复、原子批量修改、模板 CRUD、异常恢复与冷却、渠道选择。前端测试覆盖复制、换绑、参数编辑、模板、版本比较与恢复，以及原有 RSS 编辑和模拟逻辑。浏览器验收使用隔离内存数据，不代表真实 RSS、115、下载器或通知服务的外部联调结果。
