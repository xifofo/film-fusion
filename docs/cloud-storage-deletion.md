# 云存储删除保护

`DELETE /api/cloud-storage/:id` 只允许删除当前用户拥有且已无占用的云存储配置。

删除前检查以下位置，停用的配置也仍算引用：

- 媒体目录、302 匹配规则、302 负载均衡账号池、Emby 账号绑定。
- 自动化触发源、流程节点、模板，以及等待或运行中的自动化执行快照、上下文和节点输入输出。
- 未完成的 115 下载队列、整理预览、整理恢复、源文件夹延迟删除任务和有效云盘操作锁。
- 正在执行的整理计划、仍在托管的 STRM 文件、尚未清理或仍在传输的 302 缓存分配。

已软删除的媒体目录、已完成的下载和预览、已完成或回滚的恢复任务、过期操作锁、已退役 STRM、已清理且不在传输的 302 缓存，以及历史日志、文件识别缓存和自动化历史版本不阻止删除。失败但仍需重试或恢复的下载、预览和整理恢复任务须先处理。

存在引用时返回 HTTP 409，`message` 包含存储名称、占用位置、关联名称或路径及 ID，直接兼容现有前端单条和批量删除的错误通知；`data.references` 提供结构化位置、总数和示例。每类最多显示十个位置，超出部分显示剩余数量。解除引用后重试即可删除，不自动解绑 Emby 账号或修改其他业务配置。

不存在、已删除或不属于当前用户的存储统一返回 404，避免暴露其他账号的占用信息。引用检查或数据库操作失败返回 500，保留存储及其关联。校验与软删除在同一 SQLite 写事务内完成，失败时整体回滚。删除只影响 FilmFusion 配置，不调用网盘文件删除接口。

验证：`go test ./app/service ./app/handler -run 'TestDeleteCloudStorage'`。测试使用临时 SQLite 数据库，不操作真实网盘或线上配置。
